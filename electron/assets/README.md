# electron/assets — Icon files

All raster icons must be generated from the SVG sources in this folder.

## Required PNG files

| File | Size | Used for |
|---|---|---|
| `icon.png` | 512×512 | macOS `.app`, `.dmg`, Windows installer, About dialog |
| `icon.icns` | — (generated by electron-builder) | macOS bundle icon |
| `icon.ico` | — (generated by electron-builder) | Windows taskbar / installer |
| `tray-icon-mac.png` | 22×22 | macOS menu bar (1× / non-Retina) |
| `tray-icon-mac@2x.png` | 44×44 | macOS menu bar (2× Retina) |
| `tray-icon.png` | 16×16 | Windows system tray / Linux |
| `tray-icon@2x.png` | 32×32 | Linux HiDPI |

## Generate PNGs from SVG (requires `sharp` or `svgexport`)

```bash
# Install once
npm install -g svgexport

# Full-colour app icon
svgexport electron/assets/icon.svg electron/assets/icon.png 512:512

# macOS monochrome template icon (tray-icon-mac.svg is already black-only)
svgexport electron/assets/tray-icon-mac.svg electron/assets/tray-icon-mac.png 22:22
svgexport electron/assets/tray-icon-mac.svg electron/assets/tray-icon-mac@2x.png 44:44

# Windows / Linux tray icon (colour version)
svgexport electron/assets/icon.svg electron/assets/tray-icon.png 16:16
svgexport electron/assets/icon.svg electron/assets/tray-icon@2x.png 32:32
```

## macOS template image

The macOS tray icon is declared as a *template image* in `electron/main.js`:
```js
icon.setTemplateImage(true);
```
This tells macOS to automatically invert it when the system switches between
light and dark mode. Template images **must be black (or grayscale) on transparent**.
Use `tray-icon-mac.svg` as the source (no rounded rectangle, no colour).
